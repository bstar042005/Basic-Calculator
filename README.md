# Basic Calculator

A simple calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

* Addition of two numbers
* Subtraction of two numbers
* Multiplication of two numbers
* Division of two numbers
* Clean and simple user interface
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```
Basic-Calculator/
│
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder.

3. Double-click `index.html` or open it in your browser.
